# 音声だけの削除対象確認

2026-10-06に、音声だけを削除するための読み取り専用検査基盤を追加した。保存済みトラック、アプリ内の原本コピー、録音の残りファイル、解析用PCMを、保持する文書・結果・履歴から区別する。本記録の検証範囲は対象確認と再照合である。同意保存と未開始保持は後続の[同意保存と未開始保持](audio-only-deletion-consent-2026-10-06.md)で内部接続した。限定したファイル処理と中断後の続行は後続の[ファイル削除と中断後の続行](audio-only-file-removal-2026-10-06.md)で内部接続した。利用不可判定・操作完了・画面接続は残件であり、M3-07と実装計画全体は進行中を維持する。

## 対象と保持範囲

音声資産は、会議に属する登録資産の種類と、音声チャンク・取り込みの原本／変換後資産への参照を照合する。処理済みトラックと現在の生成配置以外の登録音声も含める。存在しない登録音声は欠落として残し、内容や容量が異なるファイルは変更済みとして区別する。音声参照と資産の種類が矛盾する場合、対象を保持して検査を止める。

録音・取り込みの残りファイルと解析用PCMは、同じ会議のセッション・取り込み・ジョブIDに結び付いた既知の配置だけを分類する。拡張子や近隣のIDだけでは音声として採用しない。未登録の生成物という分類も、所有権の証明や削除許可ではない。分類できないファイルは別に表示できる情報として保持する。

音声manifest、解析結果、ログ、文字起こし・議事録の公開版と固定入力版、下書き、編集履歴、根拠、ジョブ、書き出し記録を保持する。確認用情報はトラックのID・種類・状態・区間数・長さ、資産の相対パス・容量・SHA・変更分類、保持するデータの件数で構成する。音声、発言全文、議事録本文、外部の元ファイル名や書き出し先を複製しない。保持するmanifestが音声資産に誤分類されている場合は検査を止める。

## 確認後の変更検出

起動時に固定した保存領域とDBの実体、既知のスキーマと参照保護、会議の全依存データ、音声以外も含む管理ファイルの観測を再利用する。音声専用の型とハッシュを作り、会議完全削除やモデル削除の許可へ流用しない。表示用の結果には実行不可を明示する。

保持する文書の編集、トラック状態の変更、音声の変更、新しい未分類ファイルも古い確認を無効にする。保存領域やDBの置換、リンク、共有リンク、特殊ファイル、管理領域外の登録パスを採用しない。別会議のファイル、外部に置かれた取り込み元、外部書き出しファイルは開かない。

新しい検査は実行中処理と未完了の保存領域操作がある場合に開始しない。メモリー上の書込停止だけに依存せず、DB上の未完了操作も照合する。検査はDBとファイルを書き換えず、取消でもそのまま保持する。既存の全会議検査の件数・深さ・パス・容量上限を引き継ぎ、音声専用の検査証拠も64MiBに制限する。
