# 削除履歴の現行DB検査への統一

削除履歴だけで旧DBを受け入れる検査と、音声削除台帳のない旧DBへの例外を削除した。旧データの互換対応を不要とする指定に従い、削除対象と保存済み履歴は同じ現行DB31の定義・ハッシュを検査する。現行の削除同意・所有・排他・異常終了後の回復を維持する。旧議事録の構造化記録や削除記録自体の複数版の整理は別の残件であり、互換処理全体の削除完了ではない。

## 変更範囲

旧22〜30のSQL定義を組み立てて保存済み同意を検査する一覧を、現行SQL定義1つに統一した。各DBの版・SQL・トリガー・外部キー・一時オブジェクト・参照整合性は呼出しごとに検査し、稼働DBの状態をキャッシュしない。保存済みスキーマハッシュが現行と異なれば、その同意は読取り・実行に使わない。現在作成する同意の形式や既存の現行ハッシュは変えていない。

音声削除台帳がない旧20・21で音声を利用する例外も削除した。台帳欠落は版を問わず拒否する。旧27の会議・音声の同意へ変換する検査専用素材と、未使用の付随ヘルパーを削除した。モデル削除の検査は、異なるスキーマハッシュを再署名しても読取り・開始できないことを確認する。

DB表や現行データの一括削除、UIの変更、録音の開始は行っていない。QAの保存済み削除同意3件のハッシュは現行DBと同じ `057073e15717f76fd620e65c4a087570505ee6b0dcd18dde9e78431d2d1286c5` で、削除する必要はなかった。
