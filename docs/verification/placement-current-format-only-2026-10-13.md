# 現行形式だけを使う保存先変更

旧配置台帳の自動更新と、配置済みDBだけで旧スキーマを受け入れる例外を削除した。現在の配置台帳とDBについて、コピー照合・所有確認・排他・切替後の書込停止・再起動による受付は維持する。SQLiteの通常起動時の旧スキーマ更新と旧構造化記録などは別の整理残件であり、旧互換処理全体の削除完了ではない。

## 削除した処理と維持する形式

配置台帳は現在のversion 2と一致するスキーマだけを受け付ける。version 1の台帳にadmission表を追加して更新する処理を削除した。非対応台帳は書込開始前に拒否し、コピー証明・起動設定・元音声・コピー先音声を変更しない検査へ切り替えた。

配置済みDBも通常の現行DB検査を使う。旧27〜30のスキーマを例外的に受け入れる処理を削除し、現在の31だけを受け付ける。取消・スキーマ履歴・内容・所有・ファイルハッシュの検査は維持した。旧DBは拒否を確かめるテスト内でのみ構築する。

管理履歴の引継ぎDBとネイティブの配置マニフェストは、別の現行形式としてversion 1を使っている。これらは旧台帳と同じ物ではなく、今回削除していない。
