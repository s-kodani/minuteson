# 保存区間別の話者分離と特徴量の再利用

欠損付き録音の保存区間別話者分離を、固定ジョブ・中断・再試行・追加復元・候補保存へ接続した。区間を連結せず、同じトラック内だけで特徴量を照合する。合成PCMと模擬エンジンで保存・復元の整合を検査した段階であり、実会議の話者精度やMac実機録音の合格を示さない。

## 固定条件と保存区間

欠損付き音声だけ新しいジョブ形式版2を使い、保存区間・欠損・取得時計・音声manifest・エンジン・抽出ヘルパー・照合方法・人数指定・手動割り当てを固定する。連続音声の旧ジョブと結果は、追加項目を省略する従来形式を維持する。開始と候補公開のトランザクションでも現在の音声・欠損を照合する。

各保存区間を独立した16kHzモノラルPCM16のWAVへ変換する。音声のない範囲を補充せず、結果は元の会議時刻へ戻す。区間内の話者分離は自動推定し、人数指定は区間間の照合後にトラック全体へ適用する。区間ごとの同じ話者番号だけでは同一人物と扱わない。

同じ話者だけが発話する連続範囲から、最長二範囲・各最大30秒の特徴量を別々に抽出して保存する。範囲の選択は元のマイクロ秒区間で重複を除いてから完全なサンプルへ丸める。一サンプル未満の発話や重複も保持し、特徴量のためにPCMを作らない。実際に重なる話者の統合は禁止する。

特徴量不足は、区間に限定した「未照合話者」として残す。人物・信頼度・存在しない人数を作らず、重複を維持する。大量の結果を保持する前に、トラックごとの話者区間・特徴量件数・成分数を制限する。候補の話者上限を満たすために未照合話者を推測で統合しない。

## 中断と再試行

WAV・元出力・構造化した話者区間・特徴量を照合し、一つの保存区間が完了した時点でチェックポイントを進める。未完了の特徴量を候補へ公開しない。再開と固定条件の再試行は、完了済み結果を再照合して使い、同じ範囲の話者分離・特徴量抽出を再実行しない。

実行前後と公開前に、モデル・依存ライブラリ・ヘルパー・保存音声・欠損を検査する。変更時は現在の文字起こし・修正本文・氏名・手動割り当てを保持して候補公開を拒否する。欠損をまたぐ発言は本文を分割せず、推定を不明とする。確認画面の要分割表示は、変更可能な現在の欠損ではなく、結果を作った固定ジョブの保存区間から判断する。

## 追加復元とモデルの再配置

追加復元では、会議・トラック・元操作・入力版・manifestの参照を対応付け直し、特徴量ビット列・選択範囲・取得時計・モデルとヘルパーの容量とSHAを保持する。未完了ジョブも自動開始しない。チェックポイントが空でも、復元前後の人数・照合方法・音声の証拠を確認する。

モデルとヘルパーのパスは未配置参照へ置き換わる。モデル未配置でも保存済み結果は保持し、除外した一時PCMは元音声から同じWAVとして再検証できる。未完了分を実行する際は、同じモデル・全依存ファイルを明示的に配置してCPU確認を行い、既存のモデル再照合による再試行へ接続する。固定ジョブの条件と保存済み結果は書き換えない。抽出ヘルパーも同じ容量とSHAを持つ署名済み実体が必要で、異なるヘルパーへの暗黙更新は拒否する。

## 自動工程と画面

保存後の自動工程は、欠損付き音声の文字起こし候補をそのまま区間別話者分離へ引き継ぐ。結果は確認待ちの候補で、現在版を採用したり編集中の下書きを置き換えたりしない。手動開始のトラック一覧も欠損付き録音を受け付ける。

話者分離の進捗表示は「処理単位」とし、連続音声はトラック、欠損付き音声は保存区間であることを再試行確認へ表示する。人数の適用先、区間ごとの未照合話者、品質未検証の説明も追加した。

## 重点検査

先行重点検査11件は `/private/tmp/mon-known-diarization-focus5.log` で成功した。通常の構造検査6件と専用連携5件を含む。二つの5秒PCMを会議時刻0〜5秒と15〜20秒へ配置し、WAVの全サンプルがそれぞれ8192と−16384で、10秒の欠損を無音で埋めないことを検査した。

専用連携は、異なる声と同じ声の区間間照合、固定人数と自動推定の区別、特徴量不足、実際の重複と矛盾する人数の拒否、中断・冷再起動・固定再試行、モデルと欠損の変更時の公開拒否、完了済みと途中の追加復元を含む。途中復元では実際の配置・模擬CLIによるCPU確認・明示的なモデル再照合再試行を行い、保存済み区間の特徴量を再抽出せず未完了区間だけを実行した。

先行ログ `focus3` と `focus4` には失敗を残した。検査が製品DBとは別の接続を開いた誤り、指定人数を自動推定と同じ期待値にした誤り、復元後のパスを配置済みと扱った誤りを修正した。SQLiteの排他管理や固定人数の製品処理は弱めていない。
