# AIモデルの手動取り込み前の検査

2026-10-05に、設定画面へ手動パッケージの事前検査を接続した。対象は仕様10.10・DATA-09・モデル導入に必要な入力検査である。ファイルの整合と申告された対象OS・CPUを検査するが、モデルの導入や実際のエンジン互換性はまだ確認しない。準備完了とは扱わない。

## 実装範囲

設定の「AIモデル」でパッケージフォルダーの絶対パスを指定する。直下の `mon-model.json` に形式版1、エンジンとその版、モデル名・版、任意の量子化情報、ライセンス参照、対象OS・CPU、構成ファイルを記載する。whisper.cppは実行ファイルとASR、sherpa-onnxは実行ファイル・segmentation・speaker_embedding、llama.cppは実行ファイルとLLMが必要となる。whisper.cppのVADは任意、実行依存ライブラリは最大16件まで指定できる。全ファイルは最大64件、manifestは64KiBまでとする。

相対パスの逸脱、絶対パス、ドライブ・ストリーム指定、危険な名前、重複、ファイルと親フォルダーの衝突、リンク参照を拒否する。空ファイルは受け付けない。指定された容量・SHAがあれば実測と照合し、指定がなくても容量・SHAを計算する。64KiB単位で読み、途中取消と増大を検出する。開始・終了時のファイル・親ディレクトリ情報とUnixの実体識別子・変更時刻を確認し、検査中の差し替えを拒否する。

検査はメイン画面専用の非同期RPCで実行し、全体で1件に限定する。取消要求だけで次の検査を許可せず、元の処理が終了するまで操作ガードを保持する。画面切替でも取消を要求し、古い応答を表示しない。エラー時は前回の成功結果を消し、入力と原因を画面に残す。

実装はモデル・実行ファイルを起動しない。ネットワーク、DB、会議、既存ジョブ、解析設定への書き込みを行わず、元ファイルも変更しない。manifest未記載のファイルは検査対象外であり、必要なモデル・ライブラリをすべて列挙する必要がある。

## 検査結果の意味

結果は今回読み取ったmanifestのSHA、各ファイルの役割・容量・SHA、指定値との一致を示す。状態は常に未導入・準備未完了で、エンジン互換性と配布元の真正性は未検証とする。manifestに書かれたエンジン版・ライセンス参照は申告情報であり、動作や配布許諾を証明しない。ローカルSHAや入力manifestとの一致を配布元認証と表示しない。

## 検証結果

- Rust追加9件で、3エンジンの構成、指定SHAなし、危険なパス・重複・役割違い・対象違い、欠損・空・容量/SHA不一致、未知/重複フィールド・大きすぎるmanifest、リンク、検査中の変更・差し替え、途中取消と操作IDの寿命を確認した。対象違いの検査はローカルの列挙値検査であり、Windows実行検証ではない。
- フロントエンド追加2件で、事前検査を導入済み・準備完了と誤表示しないことと、取消・古い応答の抑止を確認した。
- Playwrightと模擬IPCで、設定画面の成功表示、エラー後の古い成功表示の消去、検査中の入力禁止、取消要求と遅延成功の競合、画面切替後の遅延応答抑止を確認した。記録した呼び出しに録音・解析開始・保存がないことも照合した。1440pxと760pxの表示を確認した。ネイティブWebViewの実IPC検証とは区別する。
- 最終コードの `make check` は終了コード0。Python65件、フロントエンド66件、Swift9件、Rust通常401件（11件ignored）、AVFoundation製CAF読出し1件が成功した。評価設定はエラー0・前提不足の警告7件。Swiftのユーザーキャッシュが書き込み不可という警告は残る。

検査に使用したファイルは合成fixtureであり、実モデルの互換性・性能・品質の証拠にしない。録音は行っていない。

## 次に必要な実装

今回の結果はインストール権限や再試行時の信頼済み入力として使わない。手動導入時にはファイルを再照合し、OSアプリデータ領域へのコピー・同期・中断回復、エンジンでの実ロード検証、モデルDBの状態確定、使用中モデルの保護とプロファイル選択へ接続する必要がある。ダウンロードと配布元情報の検証も未実装である。

導入済みパッケージとプロファイル全体のバックアップ・追加復元、復元後の明示的な再処理、復元コントローラー、構築用一時領域の起動時回収も残る。M3-06・M4-02を完了扱いにしない。正式評価とWindows固有の実装・CIは引き続き保留する。
