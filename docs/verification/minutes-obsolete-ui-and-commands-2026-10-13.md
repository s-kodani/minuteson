# 議事録の旧編集画面と公開操作の削除

高度編集と「根拠の発言」の画面・再生処理を削除し、議事録の公開操作を現在のMarkdown生成・編集・保存・書き出し・区間再生へ絞った。既存の会議・音声・モデルは削除していない。内部の旧生成・下書き・候補採用・版復元のメソッドの整理は残っており、議事録簡素化全体の完了とはしない。

## 削除した処理と維持する保存機能

高度な書式編集、ブロック編集、根拠チップとパネル、固定文字起こし、専用ページ切替など9部品をソースから削除した。専用スタイルと旧機能だけの画面・単体検査も除去し、テスト用サービスから候補・根拠・版切替の模擬実装を削除した。

旧生成、プレビュー、議事録版一覧、旧下書きの作成・保存・Undo、候補採用、版復元、旧書き出し、根拠と固定文字起こしの参照・再生の16公開コマンドは、登録と実装を削除した。ネイティブの根拠参照・再生モジュールも削除した。現在の再生準備は、発言、分割した発言、会議全体、Markdown区間の4経路を維持する。

Markdownの明示保存、生成中の後続編集の保護、未保存で離れる確認、生成結果の直接保存、同条件再試行、本文そのままの書き出し、区間の音声検証と解放は変更していない。保存済みの旧議事録本文を読み出す更新処理と、現行形式の会議バックアップを残す。DBの初期化や旧データの一括削除は行わない。

## 検証結果と範囲

作業ソースとQA用ソースで、最終のフロント単体各848件、型検査と構築が成功した。廃止機能の検査を除去したため前回929件と件数・範囲は異なる。追加した3件は、削除した公開操作の実装・登録・再生要求がないこと、旧部品と専用スタイルの実体削除、現行画面用サービスが旧操作を受け付けないことを検査する。IME検査は旧リッチ編集から、通常のテキストエリアと変換中の明示保存保護へ切り替えた。

関連Rust67件は全成功・ignoreなし。ライブラリの関連範囲を一度実行し、Markdown保存・生成・書き出し、旧保存本文の読出しと再起動相当の保持、会議音声と区間再生を合成データで確認した。全2006件のRust全体成功とはしない。

WebKit・Chrome系は最終各52条件成功。議事録のプレビューと手動保存15条件、Markdown出力8条件、区間再生8条件、全体設定の生成6条件、文字起こし再生成8条件、会議名フォームを含む会議画面5条件、共通設定とキーボード各1条件を含む。明暗・広幅・狭幅の画像を確認し、フォームの角丸・枠線・高さと議事録の余白が維持されている。画像と結果は `output/playwright/minutes-cleanup-webkit-20261013/` と `output/playwright/minutes-cleanup-chrome-retry-20261013/`。

最初のChromeでは再生成成功後に古い競合警告が残り、警告が消えるのを待つ条件で停止した。状態を読み取り、本文と生成状態は成功しているがトーストだけが残っていることを確認した。同じ条件を変更せず再実行して52条件が成功したが、最初の表示残留を解決済みとはせず、非同期通知の残件とする。途中の単体検査は削除した機能のCSS期待値、新しいIME検査の誤った期待値、QA構築時の一時パス差異で失敗した。製品の保存・競合・解放条件は緩めず、検査を現行機能へ合わせ、構築スクリプトを製品と同じ内容へ戻して再検査した。別フォルダーでの構築・単体の起動失敗も工程記録に含める。

画面は合成IPCと無音PCM、Rustは専用一時領域の合成データを使用した。実録音、実モデル生成、新QAのMac画面操作、使用中QAや既存会議の変更、OS許可変更、VoiceOver、CIは今回の検証範囲に含まない。

## 残対応の目安

内部の旧議事録生成・下書き・候補採用・版復元の処理を、既存本文の読出しと現行バックアップの検証から分離して削除する作業は2〜3時間。公式モデル候補追加は1〜2時間、実モデルと日本語入力を含むMac統合確認は2〜4時間。既存WebKit共通モーダルのフォーカス待機と、再生成後の古い警告が残る条件の調査はそれぞれ30〜60分。

短い実録音は静かな実施時間の再承認後10〜20分、4時間録音は別途合意が必要。正式配布は署名・公証の認証情報が未用意。正式評価・10話者・Windowsは保留、VoiceOverは対象外で、全開発目標は未完了。
