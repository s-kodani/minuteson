# sherpa-onnx 話者分離の接続検証

正式評価と Windows 固有部分を保留にしたまま、話者分離に必要なネイティブ実行・全トラック前処理・区間照合を実装した。提供済み音声の30秒区間で自動推定と3人指定の実行・出力検査が通った。ジョブ管理、保存済み編集を固定した入力、候補保存、画面への接続はまだ行っておらず、M2-05・M3-03の完了を意味しない。

## 実装範囲

- `diarization/sherpa.rs` はシェルを使わず、絶対パスの CLI に CPU・スレッド数・区間モデル・埋め込みモデル・クラスタリング・最小区間長・窓移動比率を明示して渡す。人数は対象トラックへの指定で、自動推定時は未指定とする。受付範囲1〜100人はデータの安全上限であり、10話者や100話者の精度を確認した値ではない。
- CLI・両モデル・申告された同梱ランタイムのパス、サイズ、SHA-256を開始前と終了後に照合する。処理中の差し替えも検査する。子プロセスへ環境変数を引き継がず、ライブラリの事前ロードや検索先の上書きを避ける。静的バイナリはランタイム一覧を空にできるが、共有版の同梱ライブラリ一覧を自動発見する機能は未実装。
- 固定設定の出力、開始行、3桁の小数秒、話者ラベル、順序、区間・人数・サイズを検査する。空の正常出力は無発話として保持し、単なる正常終了や形式不明のログを結果にしない。信頼度は作らず、シルエット値を識別確率として取り込まない。
- 全トラックの16 kHzモノラルPCM16 WAVを、約1秒の音声とフィルター前後の小さなバッファで書き出す。全音声を前処理用メモリへ展開せず、バッファ間のリサンプリング位相・文脈を保持する。トラック全体を一度にクラスタリングし、短い窓ごとに話者IDを振り直さない。RIFFサイズとネイティブのサンプル数上限では明示的に失敗し、音声を切り捨てない。
- `diarization/timeline.rs` は同一話者の重なりを追加人数と数えず、異なる話者が同時に存在する正確な時間区間を求める。単に境界で接する区間は重複ではない。文字起こし内で順番に話者が交代する場合や、同時発話の前後に別話者が含まれる場合は分割確認待ちとして区別し、単語時刻を推測して本文を切り分けない。この処理自体は本文・DB・現在版を変更しない。
- 一時停止・取消相当の要求とタイムアウトでは子プロセスを終了・回収する。未完了の呼び出しから結果は返さず、入力WAVとログを上書きしない。アプリ自体の強制終了後の子プロセス監視は引き続き残件。

## 自動テスト

話者分離10件と全トラック変換2件を追加した。設定やラベルの不一致、不正・過大な出力、モデル・ランタイムの実行中変更、子プロセスの停止・タイムアウト・失敗、同時発話と話者交代の区別を検査する。8〜384 kHzで全トラックの分割バッファと既存の一括窓変換が全バイト一致すること、音声ファイル境界と既存124秒のASR上限を越えても変換が継続することを確認する。

`make check` は Python 65件、フロントエンド39件、Swift 5件、Rust 161件に合格し、別枠のAVFoundation CAF読出し1件も通った。Rustの実エンジンなど7件は通常の実行では除外する。話者分離の実エンジン1件は以下の条件で別途実行した。評価前提の不足7件は警告のまま残す。本体のワーカーから未使用の接続部には `dead_code` 警告18件があり、抑制せず未接続であることを残している。

## 実エンジンの条件と結果

2026年10月4日、macOS 27.0 build 26A428、Apple M1 Max、arm64、32 GiBで実行した。[公式 v1.13.8 リリース](https://github.com/k2-fsa/sherpa-onnx/releases/tag/v1.13.8)の `osx-arm64-shared-no-tts` バイナリ、[公式モデル配布](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-segmentation-models)の Pyannote segmentation 3.0、[公式埋め込みモデル配布](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-recongition-models)の 3D-Speaker ERes2Net を一時領域へ取得した。既存の提供済み30秒CAFをローカルで処理し、音声は外部送信していない。

CPU・2スレッド、クラスタリング閾値0.5、窓移動比率0.1、最小発話長・結合ギャップとも0秒、信頼度計算なしを試験の固定設定とした。CLIの[人数指定と出力](https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.8/sherpa-onnx/csrc/sherpa-onnx-offline-speaker-diarization.cc)に対応する接続を検査した条件であり、日本語精度が最良になる設定を選定した結果ではない。

| 条件 | 取得した話者区間 | 呼び出し時間 |
|---|---|---|
| 自動推定 | 18区間 | 11.503秒 |
| 対象トラックに3人指定 | 12区間 | 12.011秒 |

時間はファイル照合・プロセス起動・出力検査を含む `run_track` の計時であり、WAV前処理や文字起こし・DB保存を含む解析全体ではない。同時にローカルテストも実行しており、性能比較用の統制試験ではない。3人指定の実行成功は、録音の実際の人数や話者割り当てが正しいことを証明しない。

再現用の一時領域は `/tmp/mon-sherpa-integration.2ZC5B6`、入力は `/tmp/mon-whisper-integration.ibH0yg/input.caf`。試験で生成した区間・ログ・WAVは各テストの一時フォルダー終了時に破棄し、会議の本文や音声をGitへ追加していない。取得ファイルとコマンドログは再試験用に保持した。

## 続く実装と未検証事項

固定した編集済み文字起こしを入力にするジョブ、全トラック単位のチェックポイント・再試行、元の認識本文と修正本文を保持する候補の原子的保存、人数指定・生の重複区間・分割確認のUIを接続する。別トラックの同じ番号を同一人物と見なさず、ユーザーの確認前に現在版を切り替えない。

日本語の話者精度、重複検出精度、10話者、必須16GB端末、4時間の推論メモリ・処理時間、トラック間エコー照合、Windows、macOS WebViewでの統合操作は未検証。全トラック前処理のバッファ制限は、ネイティブ推論のメモリ量まで制限・保証しない。モデルと同梱ライブラリの配布許諾・ライセンス一式の確認、採用モデルの選定、アプリへの同梱と準備UIも残件とする。
