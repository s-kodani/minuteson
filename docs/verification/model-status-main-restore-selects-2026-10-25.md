# モデル使用状態・最小化復帰・録音セレクト表示の修正（2026-10-25）

## モデル使用状態

更新後に使用中のWhisperが「VADを追加して使用」、話者分離が「ダウンロードして使用」と表示される報告を調査した。

端末内のモデル定義とインストール済みカタログを読み取り比較すると、Whisperには既にSilero VADがあり、Whisperの実行ファイル以外のモデル構成は一致した。話者分離の構成ファイルは全件一致していた。同梱ランタイムをまとめた取得アーカイブのハッシュがビルドで変わる一方、Whisper・Sherpaの再利用判定が取得定義全体の一致を要求するため、使用中の配置が画面上の利用可能な候補から外れていた。

表示判定を取得定義の再利用判定から分離した。対象モデル、保存済み設定、最新の互換性確認操作、必要なモデルファイルの容量・SHAが一致する適用済み構成は「使用中」と表示する。VAD追加は要求されたVADの実体情報が不足・不一致の場合に限る。導入済みモデルがあって実行環境の準備が必要な場合は「実行環境を更新して使用」と表示する。

別の実行環境を準備・適用する処理の取得定義照合、互換性確認、設定適用の検査は変更していない。利用者のモデル・設定・会議データは変更していない。稼働中DBの読取りは排他ロックで拒否され、定義ファイルの読取り比較だけを行った。

## 最小化したメインの復帰

ミニパネルの `open_main_window` は `show` と `set_focus` だけを実行していた。表示後に `unminimize` を実行してからフォーカスを移すようにした。各操作が失敗した場合は既存のウィンドウ操作エラー処理へ返す。録音の開始・停止処理は変更していない。

## 録音画面のセレクトボックス

録音画面の `background` 一括指定が既存の矢印画像を消していたため、背景色だけの指定へ変更した。マイク、PC音声、対象アプリ、話者数、録音中のマイク欄に明瞭な▼と区切り線、薄い背景色、ポインター、ホバー・フォーカス表示を付けた。強制カラーではOSのネイティブ矢印を使用する。入力は引き続き標準のselect要素である。
