# 文字起こしのMetal対応と速度確認

2026-10-16。macOSの同梱whisper.cpp v1.9.4をCPU専用からCPU・Metal対応へ変更した。tiny / base / small / mediumの重み、beam size 5、日本語・非翻訳、用語ヒント、非音声トークン抑制、120秒＋前後2秒の分割条件は変更していない。

## 実行条件

新しく開始するmacOSの文字起こしには `accelerationPolicy: autoMetalV1` を保存し、実行時のGPU利用を要求する。保存されたプロファイル・モデルの照合は従来どおり行う。フィールドのない旧ジョブは元の `useGpu` を維持する。再試行・再開では保存した方針を保持し、バックアップ復元でも変更を拒否する。GPUが見つからなければエンジンのCPU経路を使う。GPU要求と実際のGPU利用は区別し、実測時は `whisper_backend_init_gpu: using MTL0 backend` を確認した。

ビルドは固定ソースcommit `927cfce34f31707e17f2bff35c349632fb9e2c3a` のまま、`GGML_METAL=ON` と `GGML_METAL_EMBED_LIBRARY=ON` にする。[固定版の公式CMake定義](https://github.com/ggml-org/whisper.cpp/blob/927cfce34f31707e17f2bff35c349632fb9e2c3a/ggml/src/ggml-metal/CMakeLists.txt)に従い、シェーダーを静的実行ファイルへ埋め込む。利用者によるシェーダー配置や開発ツール導入は不要。arm64・minimum macOS 15.0・アドホック署名とシステムライブラリ限定を実バイナリで検査した。パッケージは4,556,800 bytes、構築・検査26.26秒、既存の固定ソースを再利用してソース追加取得0 bytes。CMake 4.1.2は一時領域だけに展開した。

旧CPU用キャッシュは保持し、新しい構築先を `.cache/whisper-metal-runtime/package` とした。以前のCPU専用エンジンで準備したモデルは、更新版アプリの「設定 → ローカルAI」で同じモデルの「ダウンロードして使用」から更新する。重みが同じでも旧取得定義を新エンジンの代わりに再利用しない。モデル名と導入済み一覧の集約は維持する。起動だけで既存の会議・モデル・設定を変更しない。

## 実測

Apple M1 Max、同一の124秒PCM WAV、各モデルの同一重み、4スレッド、同一のCLI・認識引数で比較。CPUだけ `--no-gpu` を指定した。各値はプロセス起動から終了までで、アプリの前処理・照合・話者分離は含まない。GPUの2回は別プロセスで、OSのシェーダーキャッシュが残るため完全な冷起動計測ではない。Rust構築と並行した参考値であり、専有環境の正式性能評価ではない。

| モデル | CPU | GPU 1回目 | GPU 2回目 |
|---|---:|---:|---:|
| Whisper base | 29.089秒 | 4.442秒 | 3.691秒 |
| Whisper medium | 59.356秒 | 8.999秒 | 8.977秒 |

CPUとGPUの認識本文・分割には差がある。正解文字列を用いたCER/WER測定は行っておらず、同等品質を保証する結果ではない。速度改善を確認した2モデル以外の速度、長時間会議、最低対応OS・メモリ構成は未測定。元の音声とモデルのSHAが実行前後で同じことを確認した。
