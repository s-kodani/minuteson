音声モデルは合成10秒無音の処理で、実発話の認識・話者分離や品質を確認したものではない。Qwenは短い合成発言による保存処理の検証で、議事録品質や60分性能の合格ではない。全9候補のMac画面操作と製品統合が完了したとも扱わない。

実素材の取得だけをローカル読取りに置き換え、通常の固定recipe・サイズとSHA・archiveの選択展開・管理配置・CPU確認・設定適用を通す。ネット通信やGUIの模擬を実取得の合格にしない。各候補のStorage・配置先は検査自身が作ったTempDirで、1候補のstageと管理コピーが共存し、検査終了時にそのコピーだけを回収する。Whisper4候補の一時コピーは1候補ずつ入れ替え、4候補分を同時に保持しない。

各適用後は構成部品が1件だけで、3エンジン全体が準備完了したとは扱わない。もう一方のprofileは不変、会議は0件を確認してから、LLMだけは別の合成会議を作って製品生成へ進む。実行・適用を通常検査や起動時に自動化せず、明示実行のignored検査と環境変数の素材指定を要求する。

Whisperの実行ファイル・index・TARは最新QAの `Contents/Resources/asr-runtime` を検査して再利用した。tinyは `/private/tmp/mon-real-ai-qa.T3hkeF/ggml-tiny.bin`、smallとライセンスは以前の固定取得payload、base・mediumとQwen Q8は[追加取得の記録](remaining-model-assets-2026-10-13.md)にある専用領域を使う。int8は同じ取得済み公式segmentation archive内の `model.int8.onnx` で、1,540,506bytes、SHA256 `d582f4b4c6b48205de7e0643c57df0df5615a3c176189be3fc461e9d18827b5d`。標準版とは別の固定memberを検査し、定義を標準版へ差し替えない。

## Qwen Q8の生成と保存

適用した全体設定から通常の `enqueue_markdown` と生成dispatcherへ渡し、管理モデルの証明・固定入力・厳密なparser・本文ハッシュとジョブ成功を確認した。初回55.711秒・27bytes、人間の保存後の明示再生成54.989秒・27bytes。再生成の登録だけでは人間の本文を上書きせず、明示操作と保存状態の一致後に置換する。Storageを閉じて開き直した後も、本文・両ジョブの成功・全体設定・profileが一致した。構造化議事録の版・項目・根拠テーブルは0行で、旧版バックアップは作らない。

使うモデルSHAはQ8の `d7efb072e7724d25048a4fda0a3e10b04bdef5d06b1403a1c93bd9f1240a63c8`。モデル別の最大入力32768・最大出力8192・最大合計context32768を独立して保持する。入力の余裕を理由に最大出力を増やす仕様へ変えていない。27bytesの短い本文が保存できたことを、要約品質の合格に置き換えない。

## 自動検査と工程時間

通常の関連Rustは26件成功・失敗0件・専用7件ignore、1946件対象外。Qwen Q8、Whisper4候補のループ、int8の3件は各 `--ignored --exact` で明示実行し、各1件成功・失敗0件・1978件対象外だった。Whisper4候補を4件のテスト成功へ水増しせず、通常26件と専用3件を分ける。作業用と構築用の単体は各863件成功した。全Rust検査の合格ではない。

| 工程 | 構築秒 | 実行秒 |
| --- | ---: | ---: |
| 通常関連Rust | 346.75 | 15.75 |
| Qwen Q8の実モデル検査 | 0.55 | 215.83 |
| Whisper4候補の実モデル検査 | 0.54 | 95.09 |
| 話者分離int8の実モデル検査 | 0.50 | 6.43 |

実装・検査更新・記録は個別未計測で概算15〜25分。作業用単体3.28秒、構築用単体2.37秒、コメント修正後の最終単体は作業用3.95秒・構築用3.94秒で各863件成功。構築合計348.34秒、約5分48秒、計測済み検査合計346.64秒、約5分47秒。3件の実モデル検査は同じキャッシュの排他下で順番に実行し、実経過492.58・587.32・592.88秒には先行検査と構築の待機が含まれる。工程時間を単純合計して実際の経過時間としない。Rustの実行時間は検査列挙・起動を含み、キャッシュ回収は個別未計測である。

通常検査の終了後に再構築可能なキャッシュ4549.6MiBを回収し、終了後は10147.2MiB、約9.91GiBを保持した。構築中の回収や別のテストキャッシュ作成はしていない。10GiBは終了後の目安で、構築中の最大容量の保証ではない。モデル原本・会議・使用中の設定は削除していない。今回のソース変更はcfg(test)だけで、最終の2行の変更も一時コピーについてのコメントだけである。
