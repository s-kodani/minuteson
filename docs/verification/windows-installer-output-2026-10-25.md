# Windows配布フォルダーの整理

配布先 `output/windows-qa/` には最新版の `MON-QA-setup.exe` だけを置く。公開版は `output/windows-release/MON-setup.exe`。アプリのビルド成功後、公開版の署名検証も完了してから配布する。

`tools/publish-windows-installer.ps1` はコピーのSHA-256を照合し、既存ファイルは置換で更新する。新しい配布物の照合が終わってから、既知の古いMONインストーラーを削除する。ログ・画像・スクリプト・ハッシュなどは隣の `windows-qa-work/` に移し、同名の証跡を上書きしない。見慣れない実行ファイルも削除対象にしない。保存先はワークスペース内に限定し、ジャンクションなどのリンクは拒否する。

2026-10-25に配布先を整理した。7つの従来名のインストーラーは、最新1つを固定名に配置・照合した後に削除した。その他の233ファイルと5フォルダーを作業用フォルダーに移した。最新の内容は変更していない。

- 配布物: `output/windows-qa/MON-QA-setup.exe`
- サイズ: 268,539,696 bytes
- SHA-256: `31d37e59e3a654e606cab9c86c988438661eddec84606dc9f312a13377dafaa0`
- 検証: 連続更新と1ファイル制約、既存証跡の保持、不正な入力時の旧版保持、既定の保存先、ワークスペース外の拒否、ジャンクション先の保護を5件の自動試験で確認。

アプリ本体を変更しない配布処理の変更のため、照合済みの直前のWindows QAビルドを使用した。インストーラーの実行や利用者データの変更は行っていない。
