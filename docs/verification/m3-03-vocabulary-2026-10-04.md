# M3-03 共通・会議別用語と固定ヒント

- 日付: 2026-10-04
- 対象: 仕様7.1、10.17〜10.18、14.20、M3-03 / M2-02
- 判定: 用語登録と固定ヒントの接続を追加。人数指定・話者分離・重複区間の残件を含むM3-03全体は完了扱いにしない。

## 保存と適用

SQLite v16で用語のスコープ、登録行、解析開始時の固定コピーを追加する。設定画面で共通用語、各会議の解析画面の任意項目で会議別用語を編集する。表記・読み・補足・有効/無効を保存し、各リスト500件まで、表示は50件ずつ。用語200文字、読み200文字、補足1000文字まで。表記の空欄・前後空白・同一リスト内の完全一致重複を拒否する。勝手なトリミング、文字の同一視、登録の自動省略は行わない。

リストの版番号で競合を検出し、登録行のID・作成日時を保持しながら変更行の版だけを進める。順序・行の版・内容・時刻・リストの版をハッシュ照合する。保存中の追加編集は最新の入力と保存応答を区別して続けて保存する。編集/削除・スコープ更新のDB失敗は一括ロールバックする。

開始時は有効な会議別用語を登録順に採用し、次に共通用語を加える。同じ表記は会議別を優先する。無効な会議別用語は共通用語を抑制しない（共通用語を使用したくない場合は共通側を無効にする）。別会議の用語は含めない。画面で確認した共通/会議別リストの版を送信し、開始前に変化していた場合は再確認を求める。

ジョブと固定コピーは同じDB取引で保存する。コピーは表記・読み・補足・スコープ・登録行の版・順序・リストの版・適用方式・今回の自由入力・実際のヒント・ハッシュを持つ。更新トリガーで書換えを拒否し、読込時にはジョブの固定条件・コピー内容・所有会議・元ジョブまたは同じコピーを継承した再試行の由来を再照合する。削除・改変・無関係な同一会議ジョブへの流用も拒否する。再試行は由来照合の上限と合わせ1000回まで。登録への動的な参照はなく、登録を後から変更/削除しても実行中・一時停止後の再開・同条件再試行は元のコピーを使う。

今回の自由入力に、用語のJSON配列を含むヒントを加え、`whisper.cpp`の`--prompt`へ単一の引数として渡す（`whisper-initial-prompt-v1`）。シェルを通さず、本文の無条件な置換は行わない。ヒント合計が8000文字を超えた場合やNULを含む場合は開始を拒否する。アプリによる切捨てはしないが、モデル側のトークン処理・認識効果はこの実装の検証から保証しない。

新規ジョブは条件schema 2とし、schema 1の既存ジョブには用語を後付けせず、元の自由入力・条件・ハッシュで再開/再試行する。新規の候補の処理条件にもコピーを保存し、比較画面の固定条件で確認できる。現在版・手動編集・議事録の固定入力を置き換えない。

## 画面

共通用語は設定、会議別用語は解析画面の折りたたみ項目へ接続した。会議画面の適用情報から共通の有効件数・内容・優先関係を確認できる。追加・編集・有効切替・確認付き削除・再読込・保存再試行を用意する。削除確認は登録の復元不可と過去の固定コピー保持を明示し、取消では入力を変更しない。

入力が揃うまで自動保存を待ち、入力エラー/競合時は入力を保持する。画面移動・解析開始・通常終了前は既存の保存キューを待つ。保存失敗時は移動を止め、保持した入力を修正して明示的に再試行できる。競合の再読込では未保存入力の破棄を確認し、勝手な上書き/統合を行わない。

人数指定・話者分離・重複区間の接続、10話者・16GB・正式評価・Windowsの保留/未検証は維持する。Windows CIの自動トリガーは再開せず、手動実行も行わない。
