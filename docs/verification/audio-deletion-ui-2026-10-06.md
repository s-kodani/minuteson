# 音声削除の確認画面と中断後の操作

2026-10-06に、音声だけの削除を会議一覧と設定内の専用確認・回復画面へ接続した。削除する管理音声・トラックと、保持する文字起こし・議事録・下書き・根拠テキスト・編集履歴・ジョブ・外部出力記録を区別する。保存先切替の公開拒否と、正式評価・10話者・Windows固有部分の保留は維持する。

## 対象と同意

会議一覧の「音声だけを削除」は会議完全削除と別の操作である。確認モーダルは対象IDと一致する会議名を一覧表示として併記し、音声の再生・解析・再解析と根拠からの音声再生ができなくなること、アプリ内では音声を復元できないことを説明する。会議名が読めない場合はIDの照合を案内し、名前を削除権限として採用しない。外部の原本・出力済み文書・バックアップは対象外で、媒体上の安全消去は保証しない。

確認IDに紐付く50件ずつの一覧を検査し、会議・相対パス・件数・SHA・由来区分の不一致では実行しない。登録音声、録音・取り込み由来の未登録音声、解析用PCM、元の履歴と一致する音声、保持するファイル、分類できないファイルを区別する。分類できないファイルは保持し、未登録音声を含める場合だけ別のチェックを要求する。

同意のチェックと読込済み一覧は一つの確認IDに限定する。再検査後は両チェックを解除し、遅れて返った古いページを採用しない。実行要求はサーバー保持のtoken・確認ID・操作だけで、表示パスやSHAを削除権限として送らない。保存済み方針は読取専用で表示し、続行で新しい未登録判断へ置き換えない。

処理済み数は選択した音声の永続進捗で、欠落も含む。保持対象を含む全パス一覧の位置へ対応付けず、各パスを推測で「削除済み」と表示しない。音声トラックの種類・状態・区間数・時間と、保持するテキスト・文書・履歴の件数も確認時の情報として表示する。

## 編集と共有操作の保護

新しい対象確認・実行の前に未保存編集を保存し、全ての音声再生所有者の停止と解放を待つ。待機後は現在の操作token・確認ID・接続状態を再照合し、古い同意を新しい確認へ付け替えない。保存や再生解放に失敗した場合は確認・削除を開始しない。

未完了履歴ですでに通常書込を停止している場合は、削除された可能性のある行へ編集を再保存しない。音声削除の確認・実行・応答未確定中は、会議完全削除・モデル削除・バックアップ・保存先変更・録音・AI処理などの共有操作を保護する。音声削除の完了後は会議一覧だけを読戻し、文字起こしや議事録の版を切り替えたり編集画面を再作成したりしない。

## 中断と結果の確認

停止要求後も実際のワーカーの終了を待つ。未開始の場合だけ音声を保持して中止でき、開始済みの部分削除には保持による復元を表示しない。確認画面を閉じても未完了記録と書込停止は残る。変更された未完了範囲は自動で広げず、対象を保持する。

完了後に音声が再出現した場合は、元の操作と新しい操作を別々に表示し、元の同意と履歴を変更しない新しい範囲への別同意を要求する。復元履歴や不正な履歴は一覧とエラーを残し、対応していない記録へ削除許可を与えない。

受付結果が不明な場合は別の削除を開始せず、同じ要求をそのまま再送する。対象確認の応答喪失は同じ会議または操作の状態を読戻して確認するだけで、削除を自動実行しない。成功通知は同じ会議・操作に紐付く検査済み結果からだけ表示し、停止と競合しても確定済み成功を保持結果へ変更しない。冷再起動からの解決後も通常利用には手動再起動を要求する。
