# 話者分離のエンジン進捗と処理中の設定欄（2026-10-17）

話者分離CLIのstderrにある `progress 12.50%` を読み取り、共通進捗カードとジョブ一覧へ反映する。通常のトラック単位の処理と保存区間単位の処理の両方を接続した。

## 表示と実行条件

- 表示する％は現在の処理単位のエンジン進捗。複数音声・区間では「1 / 2 処理単位」のように対象を添える。工程全体の所要時間比率は推定しない。
- stderrは既存の100msの子プロセス監視で差分だけ読む。改行とCR、途中で分割された行を扱い、行長と読取り量を制限する。不正な値や同じ実行内の後退値は無視し、ログファイルはそのまま保持する。
- `diarization-runtime-progress` は表示専用。ジョブID・固定条件ハッシュ・試行番号・処理単位・呼出順・通知順を照合する。通知はDBの完了数や成功状態を更新しない。
- エンジン100%時には不定進捗へ切り替え、「結果を照合・保存中」「この処理単位のエンジン処理 100%」を表示する。エンジン処理後の特徴量照合・検証・保存までジョブは継続する。失敗・取消・停止の既存処理を維持する。
- 停止中は保存済みの処理単位数を表示する。再開した未完了の処理単位は新しいエンジン進捗として開始する。画面移動では購読を破棄しない。
- 追加依頼により、「会議管理・録音・解析操作」では処理中の話者数設定を非表示にした。準備・待機・文字起こし・話者分離・停止処理・一時停止・中断の状況に応じた文言と、画面上部の進捗への案内を表示する。処理終了後に設定欄を戻し、同じ画面内の選択値は保持する。
