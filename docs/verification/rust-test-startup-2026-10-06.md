# macOS Rustテストの起動安定性

macOSのRustテスト実行ファイルをシンボル削減付きで生成し、テスト内容と無関係に発生していた起動失敗を再検査した。通常の開発・リリースビルドは変更せず、テストのassertと整数オーバーフロー検査を維持する。正式評価とWindows CIは対象外である。

## シンボル削減前の起動失敗

削除履歴の再移動を追加した全体検査は、Rust通常1,099件が成功した一方、既存の強制終了テスト4件が子プロセス起動の`ESRCH`（`No such process`）で失敗した。サンドボックス内外・並列4件・直列で再検査しても失敗するケースが変化した。詳細は[削除履歴の移動用固定と実体対応](deletion-relocation-handoff-2026-10-06.md)を参照。

元のテスト実行ファイルは2,069,573,424バイトで、ディスク上の署名検査は成功した。このファイルをテストを実行しない`--list`で40回起動すると、36回成功・4回ESRCHとなった。テスト内の強制終了処理を実行しなくても起動失敗が再現したため、その処理だけを原因とは扱わない。

## 一時コピーによる比較

元の実行ファイルを専用の一時フォルダーへコピーし、`strip -S -x`とアドホック署名を適用した。元のCargo成果物は直接加工していない。比較用コピーは722,484,480バイトとなり、署名検査に成功した。`size -m`でコードを含む`__TEXT`のサイズは同じ712,753,152バイトだったが、`__LINKEDIT`は1,355,300,864バイトから8,208,384バイトへ減少した。

このコピーの`--list`は200回すべて成功した。同じコピーで実際の強制終了テスト22件を並列4件で実行し、全件成功した。ログは`/private/tmp/mon-test-spawn-stripped-sigkill1.log`に保存した。シンボル削減前後で起動結果の差を確認したが、macOS内部のESRCH発生機構までは特定していない。

## Cargoのテスト専用設定

`app/src-tauri/Cargo.toml`に次の設定を追加した。

```toml
[profile.test]
strip = "symbols"
debug-assertions = true
overflow-checks = true
```

`strip`の対象とプロファイル継承は[Cargo Bookのプロファイル仕様](https://doc.rust-lang.org/cargo/reference/profiles.html)に従う。テスト実行ファイルのシンボルを削減するため、当該ファイルでのシンボル付きバックトレース・デバッガー表示には制約がある。通常の開発ビルドとリリースビルドの設定は変えない。テストの除外・追加のignored化・失敗の無視・自動再試行は導入しない。

実際の`cargo test --locked --offline --no-run --message-format=json`は終了コード0となった。成果物のプロファイルは最適化0、debuginfo 2、debug_assertionsとoverflow_checksがともにtrueだった。Rustは1.98.1、対象はaarch64-apple-darwinである。既存の大きなunwind情報に関するリンカー警告は残り、起動成功とは区別する。

Cargoが生成したテスト実行ファイルは724,227,680バイトで、署名検査に成功した。その`--list`を200回連続で実行し、200回成功・起動エラー0件・タイムアウト0件を確認した。ログは`/private/tmp/mon-rust-test-cargo-stripped-launch1.log`、ビルドのプロファイルと成果物は`/private/tmp/mon-rust-test-stripped-build1.jsonl`に保存した。

Cargo経由の`sigkill`テストも並列4件で全22件成功し、終了コード0となった。ログは`/private/tmp/mon-rust-test-cargo-stripped-sigkill1.log`に保存した。実際の子プロセス終了、冷再起動、同意・進捗・予約対象と既存データの保持の検査は継続する。

## 全体検査

設定変更後の最終コードの`make check`は終了コード0で成功した。Python 65件、フロントエンド152件、Swift 9件、Rust通常1,104件が成功し、環境依存11件と子プロセス専用16件の計27件は従来どおりignoredだった。Rust通常検査の所要時間は626.76秒で、強制終了テスト22件と削除履歴の再移動10件を含む。別実行のAVFoundation製CAF読出し1件も成功し、4800/4800フレームを維持した。ログは`/private/tmp/mon-rust-test-startup-final-check1.log`に保存した。

正式評価の前提不足と既存のビルド・キャッシュ警告は残る。Windows CIは実行せず、GitHub上のワークフローも`disabled_manually`であることを確認した。診断専用の一時コピーだけを削除し、元の成果物と検証ログは保持した。

## 検証範囲

利用者の録音・モデル・設定は変更していない。起動の反復成功はすべての環境での無失敗を保証せず、機能の全体検査とは区別する。削除履歴を含む保存先切替の公開拒否も維持しており、このテスト設定だけで切替機能を有効にしない。
