# pull後の全体検査とテスト修正

2026年10月27日、Windowsで `codex/windows-platform-foundation` を検査した。
開始時の `6d1684b` から `git pull --ff-only` で `3c4dbd6` へ更新した。
取り込んだ変更は、モデル削除操作・macOSトレイアイコンの調整と、
終了済み録音の通知取得のイベント駆動化である。

## 修正内容

- Rust全体を `cargo fmt` に揃え、CIの書式検査の失敗を解消した。
- バックアップ検査は、除外ファイルの先頭が再生成可能PCMであるという仮定を廃止し、
  対象IDと除外理由を確認する。単一WAV化で除外される旧入力音声との並び順はUUIDに依存する。
- 録音の追加復元検査は、単一WAVのmanifestと元録音のmanifestを区別する。
  元の時計区間は保存した入力計画で比較し、共通時計原点は元録音のmanifestと
  マイクトラックの設定で検証する。再生検査は共通WAVを対象とする。
- Windows合成録音の区間グループ検査では、固定値ではなく検証済み原音声の時計原点を使用する。
  実行時のQPCが固定値より小さい端末でも検査できる。
- Windowsでの対象指定通知取得に、別会議・録音中対象の除外、他録音の配送台帳を開かないこと、
  非表示時の通知抑止と保守権による停止・復帰の検査を追加した。
- 終了画面のブラウザー検査を、廃止済みのインラインエラーから現在のエラートーストへ追従させた。
  応答喪失時の再送禁止や終了の抑止を引き続き確認する。
- PythonのTOMLテストデータではWindowsパスをエスケープする。
  POSIX専用のロック・権限検査はWindowsで明示的にスキップし、
  FFmpegを使用する検査は `ffmpeg` と `ffprobe` が揃う環境で実行する。

製品の処理・保存形式・権限制御は変更していない。Rustの製品コードへの変更は書式調整のみ。
