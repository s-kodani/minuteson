# 録音中のPCM入力レベル

2026-10-08に、録音中のマイクとPC音声の入力レベルを、macOSヘルパーのPCM測定からRustの読み取りAPIと中央録音パネルへ接続した。画面を開くだけでは入力確認のための音声取得を始めず、開始確認が受け付けられた録音の準備中・録音中だけを対象にする。5秒の録音前テストはまだ接続していない。

## PCMの測定と一時報告

AVAudioEngineのマイク、ScreenCaptureKitの音声サンプル、Core Audio Tapsの受信バッファから、各トラックの直近PCM窓を独立して測定する。Float32・Int16・Int32と、交互配置・チャンネル別配置を扱い、左右が逆位相でも平均化で消さない。平均二乗平方根と絶対値のピークを正規化した振幅で保持する。範囲外、非有限、未対応形式や時計の不整合は確認不可にし、ゼロの測定値を作らない。

録音のセッションIDを正準UUID v4として起動引数に固定し、明示的な報告指定がある場合だけ測定する。停止ファイルと親プロセスの監視を必須とし、100ms間隔を目安に固定名の一時JSONを原子的に更新する。画面側も100ms間隔を目安に読み、仕様の表示用10〜20Hzに対して10Hzの間引きを使う。音声本体はWebViewへ送らない。音声受信からの経過時間はスリープを含むMach時計で数える。通常のヘルパー終了では一時報告を取り除き、保存済みmanifestには測定値を収録しない。報告の書込み失敗で録音を止めたり、保存成功を宣言したりしない。

## 録音対象と読み取り

ネイティブAPIは、現在の所有プロセスと正準録音状態のセッションIDが要求に一致し、準備中または録音中の場合だけ読む。読み取りの前後で録音状態と子プロセスの終了を確認する。録音先は開始時に確認した正準パスに固定し、ディレクトリ記述子を辿って親要素とファイルのシンボリックリンクを追わない。通常ファイル、単一リンク、16KiB上限、読み取り中の長さ・更新時刻・実体一致を要求する。

形式版・対象・単調な報告版、各トラックの必須5項目と数値範囲を照合する。同じ版の異なる測定値、版の逆行、未来のファイル時刻を拒否する。同じ報告を読み直したり更新時刻だけ変更したりしても、既に数えた経過時間をリセットしない。DB、会議、音声、録音状態は変更しない。

## 画面表示と古い値の除外

マイクとPC音声を別々に表示し、測定済み無音、未受信、確認不可、更新停止を区別する。測定済みの場合だけ平均とピークのdBFSを表示し、ゼロ振幅は有限のdBを作らず「無音」と表示する。フルスケール以上では注意を示し、表示バーだけを上限に収める。元の過大振幅はピークの文字表示に残す。

PCM窓の年齢、ネイティブ報告の年齢、API要求開始からの画面側の経過時間を合わせ、1秒を超える値を表示しない。読み取りは同時に1件だけとし、応答待ち中も古い値の除外を続ける。WebViewの単調時計に加え壁時計の進みも保守的に数え、時計の逆行はその画面の確認を無効にする。停止・所有変更・画面移動では古い値と遅い応答を採用しない。不正な確認IDは画面を落とさず、入力確認だけを利用不可にする。

入力レベルは受信した音声の測定であり、CAFの永続化や保存成功ではない。録音画面にはこの区別と、最新書込み確認が未対応であることを残す。
