# キーボード操作と発言編集の確定と取消

メイン画面に仕様14.14の6種類のショートカットを接続した。入力欄の通常操作と開いているモーダルを優先し、録音開始・停止や候補の採用はショートカットで行わない。M3-08と実装計画全体は進行中であり、macOS WebViewの実機操作は検証用アプリの権限設定と操作許可後に確認する。

## 操作範囲

| キー | 動作と条件 |
|---|---|
| Ctrl／Cmd＋N | 保存を確認して録音準備の会議名欄へ移動する。録音中は同じセッションの会議と録音状態へ戻る。会議の作成と録音開始は行わない |
| Ctrl／Cmd＋F | 現在画面に表示されている検索欄へ移動する。検索欄がない画面では通常の操作を妨げない |
| Space | フォーカスがある発言行かプレーヤーの音声を再生または一時停止する。入力欄・ボタン・スライダーのキー操作はそれぞれの要素に任せる |
| Ctrl／Cmd＋Enter | 発言本文の保存完了を確認して、その発言行へフォーカスを戻す。通常のEnterは改行のままにする |
| Esc | 発言本文をその入力欄に入った時点へ戻し、発言行へフォーカスを戻す。説明ポップオーバーでは閉じて元のアイコンへ戻す。録音終了は行わない |
| Ctrl／Cmd＋Z | テキスト入力欄ではOS標準のUndoを優先する。文字起こし領域の発言行や話者チェックボックスでは、未保存変更の保存を確認してから同じ下書きと最新の版番号で直前の編集を取り消す |

これらはアプリ内の操作であり、OS全体のグローバルショートカットは登録しない。IME変換中・繰り返しキー・他の処理で消費済みのキーから保存や取消を実行しない。開いている説明ポップオーバーとモーダルは、背後の画面移動・検索・履歴取消より優先する。モーダル内のプレーヤー自身はフォーカスがあれば操作できる。

発言行とプレーヤーをキーボードでフォーカスできるようにし、2pxのフォーカス枠とショートカットのアクセシビリティ属性を付けた。

## 保存と履歴の保持

発言本文のキャンセルでは他の発言、話者名、話者割り当て、分割構造を破棄しない。保存前の本文だけの変更なら、新規の上書き項目を除いて不要な保存を避ける。自動保存中・保存済みの場合は元の本文へ戻す変更を次の版として保存し、保存済みの履歴を消さない。

確定中に別の欄で入力が続いた場合も保存待ち行列で保持し、古い確定処理が新しい入力欄のフォーカスを奪わない。保存失敗では入力と再試行用の原因を保持し、「保存済み」や画面移動を先行させない。録音画面への移動も既存の保存ガードを通し、保存待ちの間に録音対象が変わった場合は別のセッションへ切り替えない。

## 検証結果

2026-10-07に追加7件を含むフロントエンド275件が成功し、失敗・skipは0件となった。通常のフロントエンドビルドも成功した。既存の500kB超のバンドルサイズ警告は残る。ログは`/private/tmp/mon-keyboard-unit-final.log`と`/private/tmp/mon-keyboard-build-final.log`に保存した。

本番Reactと合成IPCによる追加27ケースが成功した。両修飾キー、IME、保存前・保存中・保存後のキャンセル、保存失敗と再試行、確定待ちの入力移動、OS標準の本文Undo、保存済み・未保存の話者変更とフォーカス中のチェックボックスの取消、Spaceの適用範囲、モーダルと説明ポップオーバーの優先、録音対象変更、ライト・ダークのフォーカス枠を対象とする。音声再生は無音の合成PCMであり、実音声や録音は使用していない。追加検証の結果と画像は`output/playwright/keyboard/targeted-final/`に保存した。

最終コードの全体回帰は既存450ケースと追加27ケースを含む全39組・477ケースが一括実行で成功した。各組の結果件数と合計、実行エラーなしを照合し、ログと画像を`output/playwright/keyboard/verified-final-2/`に保存した。先の全体実行476ケースは追加26件までの検証だったため、チェックボックスの操作を加えた最終コードで全39組を再実行した。

最初の追加検証ではテキストUndoにOS標準でない修飾キーを使い、次の実行ではプレーヤーと同名の非表示説明ポップオーバーを区別できず失敗した。OS標準の修飾キーとプレーヤーのgroupロールを使うよう修正し、製品の保存・入力保護条件は緩めていない。
