# バックアップの旧形式互換削除と現行形式の検査

2026-10-11。初期開発中のため旧形式の考慮は不要とのユーザー指定に従い、M3-06の旧バックアップ互換処理と復元評価を対象外へ変更した。非対応版を安全に拒否する処理は残す。保存済みデータの削除・初期化は行わない。

## 削除した互換処理

バックアップは現在のDBスキーマ（30）だけを受け付ける。現行ライターが使う通常形式（format 2）と、削除済み音声の履歴を含む形式（format 3）はどちらも現行形式として維持する。

- format 1と旧DBスキーマ20〜29を読み込む分岐を削除。
- 旧スキーマごとに保存テーブルを増減する処理を削除し、現行テーブルの固定照合へ変更。
- モデル構成履歴を省略する互換処理を削除し、現行形式の必須項目に変更。
- 旧形式の素材変換・復元成功テストを削除。追加途中だった全旧版の復元検証と素材出力も撤回。

保存済みDBの通常の更新処理は別の範囲として維持する。その更新テスト用の旧DBはテスト専用の補助関数で作り、製品のバックアップ読込・作成からは利用しない。現行形式の音声・本文・議事録・固定根拠・用語・モデル情報・編集回復記録の検査は削除しない。

## 非対応版の拒否検査

現行の合成バックアップから形式番号・DBスキーマ番号だけを変更し、manifestのハッシュを計算し直した不正コピーを使う。これは有効な旧バックアップの再現や旧版復元成功の証拠ではない。

DBスキーマ0〜29・31と、現行スキーマのformat 0／1／4の計34ケースで、読込時の拒否・検証用展開先の未作成・通常追加復元入口での拒否・既存DB行の保持を検査する。モデル構成履歴の省略・null・改変は既存の拒否検査を維持する。
