# 固定ヘッダーと録音画面への移動

メイン画面のヘッダーとナビゲーションを、本文のスクロール領域から分離した。概要・会議一覧・設定のどこでも、録音の正準状態と経過時刻、録音画面への移動を表示する。正式評価とWindows固有部分は保留し、M3-08と実装計画全体は進行中である。

## スクロール領域と幅の切替

アプリ全体を画面の高さに収め、ヘッダーをレイアウト上で確保する。本文はヘッダーより下の領域でスクロールし、本文末尾へ移動しても録音状態・時刻・テーマ操作を隠さない。ヘッダーの項目は実効幅が狭い場合に折り返す。本文領域はキーボードでスクロールでき、フォーカス対象との余白を確保する。

1280px以上ではナビゲーションを220px、1279px以下では64pxとする。縮小時はアイコン表示にし、ボタンのアクセシブル名とツールチップを保持する。現在の画面は `aria-current` でも識別できる。

## 録音画面への安全な移動

「録音画面へ」は準備中・録音中・停止中・保存中の同じ会議を開く。待機中には表示しない。停止中や保存中を「録音中」と表示せず、受信した状態と時刻をそのまま使う。状態更新だけでフォーカスを移動しない。

明示的な移動では、先に編集中の内容の保存完了を待つ。保存失敗なら入力と現在の会議を保持し、画面を切り替えない。保存後に録音セッション・会議・版番号を再照合し、対象が変わっていた場合は古い要求で別会議を開かない。移動が成功した場合だけ概要へ戻り、録音状態へフォーカスする。録音開始・停止・アプリ終了のコマンドは発行しない。
