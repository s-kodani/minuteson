# 取り込みと用語と表示設定と回収の通知

音声取り込み・用語保存・表示設定・要確認データの回収を、メイン画面の共通トーストへ接続した。通知を閉じても未保存入力、要対応状態、保存済み結果と明示的な再試行を保持する。定期読込は結果を再通知せず、未確定の保存や回収を自動でやり直さない。M3-08と計画全体は進行中であり、正式評価とWindows固有部分は保留する。

## 取り込みと用語保存

取り込みでは保存済みの結果だけを成功として通知し、確認中・実行中・失敗を保存完了と表示しない。通知から保存した会議を開けるが、同じ音声の取り込みを再実行しない。会議を開けなかった場合は保存済み音声と結果を保持し、明示的に開き直せる。取消は成功ではなく情報として表示する。

取り込みモーダル内では原因と入力をその場に残す。モーダルを閉じた後の問題は重要通知と短い要対応表示に接続する。容量・形式の確認、進捗、会議名・用語入力、元ファイルと保存済み会議の保護は既存の経路を維持する。

共通用語と会議別用語の保存失敗は重要通知にする。会議別の編集欄を折りたたんでも要対応表示は隠さない。通知の閉鎖は入力の破棄・保存・エラーの解除を行わない。再試行は同じ保存キューを使い、対象の用語帳と最新入力を維持する。空欄・重複等の不正な入力、確認モーダル中、書込停止中は再試行できない。通常の自動保存では成功通知を出さない。

## 表示設定の保存と結果確認

テーマの結果通知は画面移動でアンマウントされない発行元へ集約した。画面内の要対応表示を別部品として保持し、同じ問題の通知を設定画面と他画面から二重に発行しない。

確認済みの保存応答は成功、応答喪失後の読戻しと明示的な再読込は情報として通知する。各結果に別の通知IDを付け、同じ文言の次の保存を区別する。古い通知の閉鎖で新しい結果を消さない。定期読込・OS追従・画面移動は通常の状態更新として扱い、完了通知を繰り返さない。

失敗時は選択と保存済み配色、要対応表示、再試行を維持する。保存結果が未確認の場合、通知から行えるのは読戻しであり、新しい保存ではない。読戻しで同じ選択の保存を確認した場合は、保存命令を増やさず問題を解消する。

ミニ画面は既存のローカル読込エラー表示を維持し、表示領域のない共通トーストへ移していない。メインとミニ画面の単一通知の振り分けと、最小化時の独立通知領域は残件である。

## 回収結果と未確定状態

回収・保持確認・公開済み会議の保持を、確定した処理IDと結果に結び付けて通知する。保持は回収と区別し、画面内には短い結果状態を残す。所有不明等の要確認が残った結果は重要通知と要対応表示にし、成功と表示しない。通知に回収・削除の実行ボタンを置いていない。

応答喪失のメッセージを通常の操作エラーから分離した。状態イベントで同じ操作の受付を確認する前後にRPCエラーが届いても、解消した未確定状態を再表示しない。未受付・別の処理ID・不正な結果では既存の書込保護と同一要求の確認を維持する。対象一覧を読めない場合の原因は、受付結果の確認だけで消さない。
