# M2-06 Markdown出力・履歴の実装確認

- 実施日: 2026-10-04
- 対象: 仕様v0.8の標準保存ダイアログ、編集済み文書のMarkdown導出、`export_records`
- 判定: macOS向け保存ダイアログとUIを接続。単体・ブラウザ模擬IPC・バンドルの確認まで。実際のmacOS WebViewと保存パネルの一連の操作は未確認。

## 保存経路

議事録と文字起こし・設定の未保存編集を先に保存し、現在版・内容ハッシュ・会議lock_version・下書きID/lock_versionを固定する。Markdownは検証済みの型付き文書JSONから導出する。候補の直接出力と、未保存編集があるままの出力は行わない。OSパネル終了後にも入力を再照合し、表示中の編集・採用・復元による変更を拒否する。

macOSでは既存キャッシュのobjc2/AppKitを用いてメインスレッド上の`NSSavePanel`を使用する。標準名は会議作成日時のローカル日付・会議名・「議事録.md」。ファイル名禁止文字と長さを制限する。保存先パス・本文を任意に指定するフロントエンドRPCは追加しない。取消時は外部ファイルと出力履歴を作らず、先に保存した編集を維持する。Windowsの保存パネルは未接続で、明示的なエラーを返す。

選択された絶対パスの`.md`のみを扱い、管理データ内・シンボリックリンク・ハードリンク・特殊ファイル等を拒否する。既存ファイルはサイズ・時刻・ハッシュ・同一性を再照合し、新規ファイルは公開直前に出現したファイルを上書きしない。同じフォルダーの一時ファイルへ書き、同期後に公開する。通常の失敗で一時ファイルを回収する。確認から置換までの極小区間を含め、敵対的な外部プロセスやネットワークファイルシステムに対する完全な競合排除は証明していない。強制終了で残った一時ファイルの回収も未実装。

## 履歴と応答喪失

SQLite v15を追加し、対象版（整理後はNULL）、操作IDと要求ハッシュ、導出元JSONとMarkdownバイト列それぞれのSHA-256、予定出力サイズ、保存先、時刻、結果を保存する。対象版が外部出力履歴のためだけに永続保持されないよう`ON DELETE SET NULL`を用いる。外部ファイルは管理音声資産へ登録せず、会議削除等による外部ファイルの削除は行わない。

選択済み保存先の拒否や公開前の容量不足は失敗として残す。ファイル公開後の同期失敗は「結果未確定」とし、結果のDB保存失敗でも成功を推測しない。起動時の`writing`は`interrupted`へ移す。履歴のサイズ・ハッシュは予定内容であり、失敗時にそのファイルが存在する保証ではない。UIは最新50件を表示し、外部ファイルの現在の存在や内容を追跡しないことを明記する。

同じ操作IDの再照会・再要求は既存結果だけを返し、外部ファイルを書き直さない。応答が失われた画面には結果確認ボタンを表示し、読取り専用照会で進行中または履歴を確認してから、新しい保存操作を許可する。出力操作は同時1件に制限し、通常終了中も出力完了・取消を待つ。
