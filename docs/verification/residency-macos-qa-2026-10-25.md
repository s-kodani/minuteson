# macOS常駐・残留防止の実機検証

Mac実機検証は利用者側で実施する。Windows上ではMacのビルド・署名・実機確認を行っていない。本書の項目に合格するまでMac実機検証済みとは扱わない。

## ビルド

既存のmacOS 15以降・Apple Silicon向け開発環境で、リポジトリを更新する。今回のソース変更には未コミットのファイルもあるため、コミット済みの旧ブランチだけでは含まれない。既存の大容量targetを再利用する。

```sh
cd app
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --lib residency -- --test-threads=1
npm run tauri:qa:build -- --config '{"productName":"MON Residency QA","identifier":"jp.mon.desktop.qa.residency20261025"}' --bundles app
codesign --verify --deep --strict 'src-tauri/target/release/bundle/macos/MON Residency QA.app'
/usr/libexec/PlistBuddy -c 'Print CFBundleIdentifier' 'src-tauri/target/release/bundle/macos/MON Residency QA.app/Contents/Info.plist'
```

期待する識別子は`jp.mon.desktop.qa.residency20261025`。検証用の専用領域で起動し、既存の会議や設定が表示された場合は操作を止めて保存先を確認する。このビルドはアドホックQAであり、配布署名・公証済みという意味ではない。

## 通常操作

1. Dockとメニューバーの両方にアプリが現れ、メニューバーに状態・「メインを開く」・「終了」がある。
2. 待機中に赤い×を押すと、アプリを終了せず画面だけが閉じる。Dockクリック、Finderから再表示、メニューバーからの表示それぞれでメイン画面が戻る。
3. 最小化、⌘H、Dock自動非表示、別アプリへの切替からも再表示できる。メニューバー項目が表示されない場合もDockから画面を開き直せる。
4. 検証用の短い録音中、保存中、解析中に×を押すと継続確認が出る。キャンセルなら画面と処理が維持され、継続なら処理を止めず収納する。
5. 録音ミニパネルの停止・メイン表示・閉じるが機能する。ミニパネルを閉じても、Dock／メニューバーからメインを開ける。
6. ⌘Q、アプリメニューの終了、Dockの終了、メニューバーの終了が同じ終了確認に入る。キャンセルで録音・ジョブが維持される。
7. 保存成功を確認する前には終了しない。保存失敗時は画面を残し、保存済みと誤表示しない。
8. ロック・スリープ／復帰中に不要な終了が発生しない。復帰後もメインを開ける。
9. 通常終了後に常駐アイコン・録音・モデル・監視プロセスが残らない。再起動で起動設定の排他に阻まれない。

マイク／PC音声の権限は検証者が確認する。許可済みの検証用音声だけを使い、実会議の録音や未保存編集を強制終了の試験に使わない。

## 監視系の異常試験

専用の合成プロセスを使い、ウィンドウ・Dock・メニューバーのすべてがない場合を検証する。1つでも利用できる場合や、OS状態を確認できない場合に強制終了しないことを確認する。

- 画面・Dock・メニューバーアイコンがすべて利用できない状態が続いた場合、5秒の復帰試行、最大20秒の安全停止猶予を経て、本体・録音・解析・監視プロセスが35秒以内に終了する。
- 途中で画面やアイコンが復帰した場合、不在の期限が解除される。
- 監視プロセスが終了した場合、本体は収納を拒否して画面の復帰を試す。画面もアイコンもなく、開き直すこともできない状態を放置しない。
- 本体を異常終了させた場合、録音プローブの親監視とモデル用ガードの所有チャンネルが機能し、配下の処理が残らない。
- 別のMON／MON QAや他アプリを終了しない。PIDだけでなく、所有者・生成時刻・専用チャンネルを使う。

Mac固有の故障注入・実時間上限・子プロセス回収は未検証として引き継ぐ。共有期限判定の単体テストとWindowsの合成プロセス試験を、Mac固有の合格結果として記録しない。

結果にはOS、CPU、ビルド識別子、署名確認、各操作の成否、画面とアイコンがすべて消えてから復帰／終了までの時間を残す。
