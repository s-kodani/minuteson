# 現行一時台帳とテーマ設定への統一

旧データの互換対応を不要とする指定に従い、一時台帳の自動更新と廃止した文字サイズ・再生追従の処理を削除した。現行の所有・排他・保存結果確認は維持する。議事録などに残る旧構造化記録の整理は別の残件であり、旧処理全体の削除完了ではない。

## 実装と旧データの扱い

一時領域台帳はMacではversion 4、他環境ではversion 2の現行SQL定義だけを受け付ける。旧0・2・3へ表を追加する更新処理を削除した。旧台帳の拒否はjournal設定変更より前に行い、保持判断・所有証明・保存先の実体・再起動時の回復を維持した。別の記録の現行version 1や2を同じ数字だけで削除しない。

表示設定はテーマのみのschemaVersion 1とした。旧schemaVersion 2の文字サイズと再生追従、保存・再試行・自動ページ移動・スクロール処理、専用スタイルと専用検査を削除した。再生中の発言は強調するだけで、編集中の本文・選択・フォーカス・ページを動かさない。ライト・ダーク・OS追従、メインとミニパネルのテーマ読取り、保存応答不明時の読戻しと競合防止は維持した。

通常QAの停止を確認した後、保存された旧表示設定1件だけを削除した。対象は `ui_preferences`、schemaVersion 2、lock_version 8、内容ハッシュ `bfa1e42a4a7e4daa9c063ce6a023f810dd2958ea039f36c8b33fb7219de29357`。変更前のDBコピーを `/private/tmp/mon-current-registry-theme-qa.9jqJ6T/before-legacy-ui-cleanup.sqlite3` に保持しており、回収可能である。テーマは既定のシステムへ戻り、会議20件・音声・モデルは削除していない。設定以外の全47テーブルの行が一致した。
