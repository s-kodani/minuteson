# 保存競合の比較画面と明示的な編集再開

2026-10-07に、文字起こしの保存競合を比較し、残す変更と未確定入力を選んで編集を再開する画面を接続した。比較と再開は読み取り専用で、確定本文も保存済み回復記録も変更しない。本文・名前の自動保存を停止し、再開後の確定・保存再試行・通常の画面移動で初めて選択結果を保存する。M3-08と計画全体は進行中である。

## 比較する内容と選択

同じ会議・下書き・解析版の比較基底、手元の保存待ち本文、最新保存版を提示する。本文と話者割り当ては別々に比較し、片側だけの変更には選択候補を示す。同じ項目を両側で異なる値に変更した場合は、明示選択まで再開できない。結果未確認の元の本文保存要求も、読み取り専用JSONで確認できる。

未確定本文・名前は、手元の全入力と保存済み回復記録の全入力をID別に提示する。保存済み側にだけ存在する入力も省略せず、各項目で手元・保存済み・再開しないのいずれかを必須とする。同じ値でも自動選択しない。入力開始時の条件もコピー可能なJSONで表示する。本文差分と入力を合わせて10件ずつ表示し、別ページの未選択入力がある場合も再開を拒否する。

本文の疎な上書きは対象発言の元値を使って比較する。本文だけの変更に付随する元の話者割り当てを、新しい割り当て変更と誤認しない。話者名の明示的な不明であるnullと、上書きの除去は区別して保持する。

## 構造の依存関係と取消

再開前に、追加話者のID・件数・ラベル、話者統合の参照・循環、分割元の本文・連続時刻・部品の連結、本文・名前・割り当ての参照と上限を検査する。これは画面側の依存検査であり、ネイティブの由来・DB・内容ハッシュ・条件付き保存の検査を置き換えない。

選択した構造では見えない分割元の本文や統合済み話者の名前を再開する場合、他の入力だけを部分適用せず、選択全体を拒否する。利用者はコピー可能な値を確認し、整合する構造を選ぶか、その入力を明示的に再開対象から外す。再開する入力の取消基底は、選択した作業本文・名前から新しく作る。古い回復記録の開始値を自動適用しない。

## 再照合と読み取り専用性

比較時と再開直前に現在の解析版を確認し、本文の所有・版・ハッシュ・内容、回復記録全体を読み直す。保存待ち本文、手元の入力、除去待ち状態、画面の存続と録音による操作制限も再照合する。読込み失敗、本文・回復記録・ローカル状態の変更では、入力と元の要求を保持して再開を拒否する。比較し直す操作は最新の条件を取得し、以前の選択を解除する。

通常は保存版が比較基底より進んだ場合だけを扱う。再起動後に最新本文を既に読み込んでいて古い回復入力だけが残った場合は、本文が同一の所有・版・ハッシュ・内容で、回復記録の基底版がそれより古く、本文と回復の未確認要求がない条件に限って比較・再開できる。同じ版を条件にした未確認保存要求の保護は緩めない。

再開成功時はローカルの基底と選択入力だけを切り替え、古い要求を再送せず外す。本文・回復記録への書込みと操作IDの発行は行わず、自動保存も停止したままにする。後続の明示保存は最新の基底版を条件にする。比較を閉じた場合は元の入力・要求をそのまま保持する。

本文と回復記録の読込みは単一トランザクションではない。最後の読込み後に別操作が進んだ場合は、後続のネイティブ条件付き保存で上書きを拒否する。再開後、次の回復保存までに異常終了した場合は、選択後の入力ではなく変更前の保存済み回復記録が残る。読み取り専用の再開を、選択結果の永続化完了として扱わない。
