# 文字起こしと話者の編集

## 解析と再生成

録音・取り込みの保存後、全体設定のモデルを使って文字起こしと話者分離を実行し、結果を発言一覧へ直接保存します。候補を比較・採用する操作や会議ごとのモデル設定はありません。処理条件と入力は開始時に固定します。

発言本文・話者の割当て・話者名を個別に修正でき、音声を再生しながら確認できます。文字起こしの明示的な再生成では置換を確認し、処理中に行った人間の後続編集を無断で上書きしません。用語や全体モデルの変更だけでは既存結果を自動更新しません。

文字起こしの保存後に話者分離への引き渡しが失敗した場合は「話者分離を再開」から続けられます。解析結果と後続の補完・照合の意図を一緒に記録し、再起動後も同じ条件・操作IDで確認します。

## 話者の割当てと補完

発言と同じトラックで正の長さだけ重なる話者区間を割り当てます。複数話者の割当ては、同時発話だけでなく発言内の逐次交代も含みます。端点が接するだけの話者は含めません。手動で設定した割当てや明示的な話者不明を保護します。

「話者割り当てを更新」は保存済みの話者区間から、自動処理で残った話者不明を更新します。本文・発言時刻を変えず、既存の割当てを上書きしません。

未検出発言の話者補完は、声の特徴量が最も近い同一トラックの話者を使います。類似度・次点との差が閾値未達、または同点の場合は要確認の印を付けます。手動で不明にした発言や音声欠損をまたぐ発言は補完しません。設定変更は次に開始する補完へ適用します。

## 登録した声

話者一覧の「声の登録・照合」から、発言候補を試聴して人物と声を登録します。欠損や他話者との重なりのない連続1秒以上の候補から1〜2区間を選び、30秒を超える区間は中央30秒を使います。

登録した声の自動適用は、類似度の下限と次点との差の下限を満たす場合に、名前が未設定の話者へ登録名を適用します。登録が1人なら類似度だけで判定します。類似度は確率ではありません。既存会議には「登録した声と照合」を明示実行できます。

設定の「登録した話者」で改名・声の削除・人物の削除ができます。登録特徴量は元音声の削除後も残り、バックアップに含まれます。

## 用語辞書

共通・会議別・音声取り込み時の用語を、文字起こしのヒントとして使います。録音開始画面の「会議の用語（任意）」で入力した用語は、開始確定時に新規会議と一緒に保存します。会議詳細の文字起こし画面にある「会議の用語」から、生成前後に確認・編集できます。再生成前には未保存の用語の保存を待ち、保存失敗時は開始しません。

| バックエンド | 使用する項目 |
| --- | --- |
| Whisper | 表記・読みをプロンプトへ反映 |
| ReazonSpeech | 表記を復号時のヒントへ反映 |
| 補足 | 保存・表示用 |

登録表記への確定後の自動置換は行いません。登録語が必ず認識されるとは限らず、似た別の言葉が選ばれる場合もあります。変更は次に新しく開始する文字起こしから反映され、同条件の再試行や過去の結果は変わりません。
