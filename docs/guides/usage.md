# MinutesOnの使い方

画面の配置と確認ダイアログ・補助ウィンドウの関係は[画面構成と遷移](../spec/screens.md)を参照してください。

## 最初の準備

対象OSに合ったアプリを準備します。配布状況は[製品概要](../spec/overview.md#配布と評価の確認状況)、自分で構築する場合は[macOS](build-macos.md)／[Windows](build-windows.md)の手順を参照してください。

1. 「設定 → ローカルAI」で文字起こし・話者分離・議事録用のモデルを選びます。
2. 未導入なら「ダウンロードして使用」を押します。空き容量を確保し、照合・動作確認・設定適用の終了を待ちます。
3. 導入済みなら「使用」で切り替えます。モデルの変更は次に開始する処理へ反映されます。
4. 固有名詞がある場合は共通用語へ表記・読みを登録します。モデルごとの「用語辞書の対応」を確認できます。

## 録音する

1. 会議一覧の「新しい録音」で準備画面を開きます。
2. マイクの自動選択／固定指定と、PC音声の全体／アプリ選択を確認します。アプリ選択では対象の会議アプリを選びます。
3. 「5秒録音して確認」で意図したマイクとPC音声が聞こえるか確認します。必要なOS権限を許可し、確認画面を閉じます。テスト音声は自動削除されます。
4. 固有名詞がある場合は「会議の用語（任意）」から表記・読みを入力します。録音開始を確定すると会議と一緒に保存されます。
5. 会議を録音し、終了時は停止を確定して保存完了を待ちます。メイン画面から離れると録音ミニパネルが表示されます。パネルを隠しても録音は停止しません。

録音前に参加者の同意と取得範囲を確認してください。全体録音には通知音や別アプリの音も含まれます。取得できない場合は[障害対応](troubleshooting.md)を参照してください。

## 保存済みの音声から始める

「音声を取り込む」からWAV・MP3・AAC/ALAC M4A・FLACを1件選ぶか、一覧へ1件ドロップします。表示された形式・長さ・必要容量を確認し、会議名と用語を設定して取り込みます。選択したオリジナルファイルは変更・削除しません。アプリ管理領域内のコピーと中間音声は、最終WAVの保存・検証完了後に自動整理します。この動作はWindows・macOS共通です。

## 発言と話者を修正する

保存後は全体設定のモデルで解析します。発言一覧で音声を聞き、本文・話者・話者名を修正します。「声の登録・照合」で人物の声を登録すると、その後の会議で照合できます。設定の閾値に従う自動適用と、既存会議への明示照合を使い分けます。

文字起こし画面の「会議の用語」から、その会議の辞書を確認・編集できます。変更は次に開始する文字起こしから反映されます。再生成前に用語の保存を完了し、保存に失敗した場合は入力を修正して再試行してください。

話者分離への引き渡しだけが失敗した場合は「話者分離を再開」を使います。「文字起こしを再生成」は既存本文と話者修正を置き換える操作なので、確認内容を読んで実行します。

## 議事録を作る

議事録タブで生成し、Markdownをプレビュー・編集・保存します。必要に応じてMarkdownへ出力します。再生成では旧版の自動バックアップを作らないため、残したい内容は先に出力してください。

## データを管理する

手動バックアップで全会議の音声・現在の文字起こしと議事録、共通と会議ごとの用語一覧、登録人物と声を一つの`.monbackup`に保存できます。話者と登録人物・声の紐付きも保持します。復元は既存データへの追加です。進捗と結果はジョブ一覧で確認でき、結果は閉じるかアプリを終了するまで残ります。会議保存先の変更、会議削除、音声だけの削除は確認画面で対象を確認して実行します。更新やデータ管理の前は録音・解析・保存中の処理の終了を待ちます。

設定の「表示」で色とライト／ダークを選べます。「内部ログ」には診断情報があり、会議本文やローカルパスを含む場合があります。共有前に内容を確認してください。
