# macOSの手動更新とデータの保持

対象はmacOS 15以降・Apple Siliconの通常版MONである。現時点では署名・公証済みDMGによる配布と通常版の実機更新を検証していない。[分離QAの合成会議によるアプリ本体の置換](verification/mac-manual-update-synthetic-2026-10-14.md)では現行データの保持を確認したが、署名済み配布更新の代わりにはならない。本手順を公開済みインストーラーの存在や通常版の更新完了の証明としない。Windowsの更新は保留である。

## 更新前

1. 更新元から、版・対応OS・署名者・配布条件と更新内容を確認する。提供元の署名／公証とハッシュを確認し、端末内で計算したハッシュだけを真正性の証明にしない。出所不明のアプリを起動したり、Gatekeeper・隔離属性を無効にしたりしない。
2. 録音・5秒テスト・音声取り込み・解析・書き出し・バックアップ・復元・削除・保存先変更を終了する。画面を閉じただけでなく、MONの明示終了を使い、停止／保存の完了を確認する。強制終了を通常の更新手順にしない。
3. 正常に保存できる状態で手動バックアップを作り、会議数・日時・名前とアーカイブの検査結果を確認する。バックアップは追加復元用であり、現在のDBを上書きする巻戻し用ではない。AIモデル、実行依存ファイルと端末内の起動設定はバックアップに含まれないため、配置先・準備状態と選択した保存先を別に確認する。モデルや設定を更新のために削除しない。
4. 起動設定・台帳・保存先に異常がある、未完了保守がある、バックアップを検査できない場合は更新を保留する。DB・WAL・台帳の個別コピーや削除、空の保存先への置換で異常を解消したことにしない。

## アプリの置換と初回起動

配布手順に従ってアプリだけを置き換える。会議保存先、モデル、設定・起動用設定を初期化しない。通常版の識別子は`jp.mon.desktop`であり、QAの`jp.mon.desktop.qa`は別領域を使う検証版で、通常版の更新先ではない。QAの設定や本番DBを互いへコピーしない。

更新後の初回起動では、保存先の実体と現行DBのスキーマ・履歴の整合を検証する。空DBの新規初期化に加え、検証済みのschema 34／35から36への限定的な追加移行を行う。過去のmigrationとchecksumを維持し、schema35からの追加前に `before-followup-intents.sqlite3` を保存する。過去会議へ自動処理の意図を追加しない。その他の旧形式DBを一律に変換しない。未対応の形式・改変された履歴・段階の欠落は拒否し、空DBで置き換えない。初期開発中の非互換データ整理は、対象と削除範囲を確認して行う別作業であり、通常更新の副作用として会議を自動削除するものではない。起動中のDBを診断用の外部SQLite接続で開かず、正常終了後に検査する。

通常起動後には、既存の未完了ジョブ・録音・取り込み等の回復処理が状態を更新する場合がある。起動後に表示された会議の保存先、件数、発言・話者、保存済みMarkdown、手動編集・用語と全体モデル設定を照合する。議事録の旧版バックアップや候補採用画面を確認項目に戻さない。許可された音声で再生・編集保存・再起動後の読戻しも確認する。ソース単体テストやQAバンドルの署名検査はこの実機更新検査の代わりにしない。

## 起動検証に失敗した場合

表示された段階と原診断、確定した保存先を保持し、終了する。診断の再読込はメモリに保持した情報だけで、修復・回収・保存先切替の再試行ではない。原因確認後の明示再起動だけが再び通常の起動検証を行う。共有する診断に個人情報がないか確認する。詳細は[起動拒否時の案内](verification/storage-startup-attention-2026-10-10.md)を参照。

非互換な開発版では、アプリだけを旧版へ戻しても現在のDBを開けるとは限らない。旧版で開くために履歴を削除・書き換えたり、DBを直接上書きしたりしない。現行形式のデータを保持する必要がある場合は、対応版・隔離した保存先と検査済みバックアップで確認する。追加復元は現行形式の既存会議を残して別会議として追加するものであり、対応するバックアップ形式6・schema36または形式5・schema35を対象とし、自動的なダウングレードや完全な環境巻戻しは行わない。

## 残る配布・更新の検証

[明示した配布ビルド経路](macos-distribution.md)を追加したが、Developer ID署名・公証済みDMGの実構築／確認は未検証。全体設定からのモデル導入と[現行8候補の短いMac統合](verification/remaining-model-integration-2026-10-14.md)は確認済みだが、正式品質・長時間性能やモデル／エンジンの配布条件の承認を意味しない。実機での通常版のアプリ置換、起動設定・保存先・モデルと会議全体の保持、Gatekeeper、失敗・中断・再起動後の統合、先行試用も確認する。資格情報の準備や公証サービスへのアップロードは別途承認と準備が必要で、本手順の更新によって実行したものではない。
