# 議事録のMarkdownプレビューとテキスト編集

2026年10月12日のユーザー指定に基づく実装変更仕様。議事録の必須機能を、生成したMarkdownのプレビューと人間によるプレーンテキスト編集・保存に絞る。現在の高度な編集・根拠の発言・候補比較・旧版復元を削除する方針であり、この仕様の記録だけで実装完了とはしない。

## 保存する内容と画面

議事録の正本は会議ごとに一つのMarkdown本文とする。プレビューとテキスト編集は同じ本文を使い、書式用JSON・構造化項目・固定発言参照との二重管理をしない。編集は通常のテキストエリアで行い、標準の貼り付け、改行、日本語変換、UndoとRedoを使える。明示保存し、保存失敗・競合時は入力を保持する。未保存で離れる場合は保存または破棄を確認する。

初回生成の成功結果をそのままプレビューする。候補を比較・採用する段階は設けない。生成後にAIが人間の編集へ介入せず、文字起こし・話者・モデル設定の変更による自動再生成も行わない。生成失敗は現在の本文を変更しない。

再生成は利用者が明示的に要求したときだけ行い、既存の編集を置き換えることを確認する。生成開始後に本文が編集・保存された場合は、古い生成結果で新しい編集を無断上書きしない。成功した置換の旧Markdownをバックアップ・直前版・比較候補として保存しない。生成中の処理進捗は本文の旧版バックアップとは区別する。

## 再生区間の記法

初期記法は `[00:12:30–00:13:15](audio:00:12:30-00:13:15)` とする。人間がMarkdownへ記述でき、プレビュー時だけ会議音声の区間再生ボタンとして表示する。時刻は開始以上の終了時刻とし、実際の会議音声の範囲を検査する。正しくない記法・範囲外・音声なしは再生せず、本文を勝手に修正しない。

これは発言の根拠管理ではない。発言ID、引用文、話者、確認済み状態、周辺発言、固定文字起こしへの移動は持たない。通常のMarkdownは安全に表示し、本文にあるHTML・スクリプトや画像の外部取得を実行しない。再生記法を外部URLとして開かない。

## 削除する機能

高度な書式ツールバー、ブロック・表・項目単位の編集、担当者・期限の編集用構造化管理、根拠チップの確認・追加・検証、根拠パネル、根拠から開く固定文字起こし、候補の比較・採用、議事録の直前版復元、再生成時の旧版バックアップを削除する。画面から隠すだけで完了とせず、専用の生成・保存・参照命令と不要な検査・モデル出力要件も整理する。

既存会議・録音・モデルのデータは削除しない。保存済み議事録を新しいMarkdown正本へ移す更新処理は、本文を失わないことを検査する。文字起こしの版管理と利用者による会議バックアップは別機能として維持する。旧バックアップ形式の互換とVoiceOverは引き続き対象外。

## 完了条件と作業順

生成経路と保存形式をMarkdownへ切り替え、プレビューとテキスト編集を接続する。その後、根拠・高度編集・議事録履歴の専用経路を削除し、会議バックアップ・出力・削除との整合を確認する。

通常生成、手動編集保存、再起動後の本文一致、日本語入力、保存失敗・競合での入力保持、生成失敗での現本文保持、再生成中の人間の編集保護、旧版バックアップの非生成、区間記法の安全な表示・再生を確認する。正式な生成品質評価は保留中のため、これらの動作確認を品質合格とはしない。
